# EC2

EC2 (Elastic Compute Cloud)
- Core Concept
	EC2 is: a virtual server in the cloud.
	You choose:
	-OS (Amazon Linux, Ubuntu, etc.)
	-CPU/RAM
	-Subnet
	-Security group

EC2 Metadata
Accessible inside instance
http://169.254.169.254
Contains:
- Instance ID
- IAM role credentials
- Public/private IP
Used by:
- Applications
- Automation scripts

EC2 User Data
- Script that runs at first boot
Used for:
- Installing nginx
- Running setup commands
- Bootstrapping server
- Executes only on first launch (unless configured otherwise)
